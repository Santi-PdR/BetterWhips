# BetterWhips — Forge 1.20.1

Authorized Forge port of BetterWhips 1.0.0, adapted from the supplied NeoForge 1.21.1 reference JAR. Original author attribution: Bhsyx.

The port targets Minecraft Forge 1.20.1 and Java 17. It preserves the twelve whips, their combat behavior, physics, networking, models, shaders, sounds, recipes, tags, advancements, and effects as they are migrated to the older Forge APIs.

Work is in progress; build status and remaining port scope will be documented as the implementation advances.
